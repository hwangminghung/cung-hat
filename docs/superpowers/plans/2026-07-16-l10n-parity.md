> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App song ngữ thật sự — mọi chuỗi UI chrome đi qua l10n (EN + VI đầy đủ), locale theo máy (fallback VI), content tiếng Việt giữ nguyên có chủ đích.

**Architecture:** Giữ nguyên hạ tầng gen-l10n hiện có (`l10n.yaml`, template `app_en.arb`, output committed). Mỗi chuỗi UI chuyển theo đúng idiom repo đã dùng: `final l10n = Localizations.of<AppLocalizations>(context, AppLocalizations);` rồi `l10n?.key ?? 'chuỗi Việt cũ'` — fallback VI giữ 369 widget test hiện có xanh nguyên (test pump không delegates → l10n null → thấy VI như cũ). Chuỗi trong code không có BuildContext (error mapper, profile_completion) refactor thành hàm nhận `AppLocalizations?`. Locale bỏ khóa cứng `'vi'` → theo hệ thống, `localeResolutionCallback` fallback VI.

**Tech Stack:** Flutter gen-l10n (ARB), Riverpod, harness test hiện có.

```dart
// thêm vào test/l10n/l10n_test.dart
import 'dart:convert';
import 'dart:io';

test('app_en.arb và app_vi.arb có cùng bộ key', () {
  Set<String> keysOf(String path) =>
      (jsonDecode(File(path).readAsStringSync()) as Map<String, dynamic>)
          .keys
          .where((k) => !k.startsWith('@'))
          .toSet();
  final en = keysOf('lib/l10n/app_en.arb');
  final vi = keysOf('lib/l10n/app_vi.arb');
  expect(vi.difference(en), isEmpty, reason: 'key chỉ có ở VI (thiếu EN)');
  expect(en.difference(vi), isEmpty, reason: 'key chỉ có ở EN (thiếu VI)');
});

test('EN locale resolves comingSoon', () async {
  final l = await AppLocalizations.delegate.load(const Locale('en'));
  expect(l.comingSoon, isNotEmpty);
});
```

- [ ] **Step 2: app.dart — theo locale máy, fallback VI:**

```dart
      // [L10N] Song ngữ: theo ngôn ngữ máy; máy đặt thứ tiếng khác → VI.
      locale: null,
      localeResolutionCallback: (device, supported) {
        for (final s in supported) {
          if (device?.languageCode == s.languageCode) return s;
        }
        return const Locale('vi');
      },
```
(thay dòng `locale: const Locale('vi'),`)
