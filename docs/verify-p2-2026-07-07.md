## ⚠️ Ghi chú quan sát (không phải regression của batch)

1. **⚠️-1 AVD `cunghat_test` segfault lặp (môi trường):** crash 3 lần trong phiên (1 lần kèm hỏng
   snapshot Dart isolate của app → "Could not prepare isolate", phải cài lại app). Khớp known-issue
   "chip segfault" các phiên trước. Đổi sang `cunghat_test3` → ổn định 100% phần còn lại. Đề xuất:
   phiên sau dùng test3/test2 làm mặc định.
2. **⚠️-2 `geo fix` console không ăn trên emulator 36.6.11 headless:** thử qua `adb emu` lẫn raw TCP
   console (có auth token, trả OK) — provider GPS trên device vẫn giữ default AVD. Xử lý bằng
   SQL + từ chối quyền location (bảng trên). Lưu môi trường cho phiên sau.
3. **⚠️-3 `input tap` đặt cursor giữa text prefill:** edit ở 5d chèn vào giữa chuỗi thay vì cuối
   (không ảnh hưởng chứng minh tính năng: prefill đúng + edit được + gửi được). adb không gõ được
   dấu tiếng Việt nên phần edit dùng ASCII (như các phiên trước).
4. **Board kèo không refetch khi đổi tab / pull-refresh** (provider fetch-1-lần, giống known-issue
